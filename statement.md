# StudyTrack – Project Statement

## 1\. Problem Statement

Students have many tasks and study different subjects. It can be hard to remember all the tasks and study time. StudyTrack is a simple program that helps students add tasks, see tasks, complete tasks, and record study time.

## 2\. Scope of the Project

This project helps students manage their tasks and study time. They can add tasks, view them, complete them, add study sessions, and check their total study time. The data is saved only while the program is running.

## 3\. Target Users

* Students who want to manage their study tasks.
* Students who want to keep track of their study time.

## 4\. High-Level Features

* Add a new study task
* View all tasks
* Mark a task as completed
* Add a study session
* View study sessions
* Calculate total study time
* Handle invalid task numbers and menu choices
