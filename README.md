# StudyTrack - Basic Python Project

## About
StudyTrack is a simple student study management program.

## Features
1. Add a task
2. Show tasks
3. Complete a task
4. Add a study session
5. Show study sessions
6. Exit

## Python Concepts Used
- Variables
- Lists
- Functions
- if/elif/else
- for loop
- while loop
- input()
- print()
- Basic calculations

## How to Run

Open the terminal in this folder and run:

python main.py

No external libraries are required.
